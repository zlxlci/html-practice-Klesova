Тег ul

Тег ul устанавливает маркированный список. Каждый элемент списка должен начинаться с тега li

Пример использования (список из 5 пунктов):

  • Изучить основы HTML5
  • Понять структуру каскадных стилей CSS3
  • Научиться связывать файлы между собой
  • Разобраться с тегами списков и таблиц
  • Создать свой первый рабочий сайт
